# Stats Command

학습 통계 요약을 제공하는 명령어입니다. Git 히스토리와 진행 상황을 분석하여 상세한 학습 리포트를 생성합니다.

## 사용법

```bash
/stats              # 전체 통계 요약
/stats weekly       # 주간 통계 (향후 지원)
/stats detailed     # 상세 통계 분석
```

`$ARGUMENTS`로 출력 형식을 선택할 수 있습니다:
- 기본 (인자 없음): 전체 통계 요약
- `weekly`: 주간 학습 통계 (향후 지원 예정)
- `monthly`: 월간 학습 통계 (향후 지원 예정)
- `detailed`: 상세 분석 및 커밋별 내역

## 응답 형식

다음 정보를 포함한 종합 리포트를 생성하세요:

### 1. 전체 진행률
CLAUDE.md 파일의 체크박스 상태를 분석하여:
- 기본 과정 (Module 1-6): X/6 완료
- 고급 과정 (Module 7-8): X/2 완료
- 전체: X/8 완료 (XX%)

시각적 진행 바를 포함하세요.

### 2. 완료 모듈 상세
Git 커밋 히스토리에서 각 완료된 모듈에 대해:
- 모듈 번호 및 이름
- 완료 날짜
- 이전 모듈과의 간격 (소요 시간)

### 3. 학습 활동 요약
- 학습 시작일 (첫 커밋 날짜)
- 마지막 활동일 (최근 커밋 날짜)
- 총 학습 기간 (일 단위)
- 실제 활동 일수
- 평균 모듈당 소요 시간

### 4. 다음 학습 목표
- 다음 미완료 모듈 이름
- 예상 소요 시간 (평균 기반)
- 남은 모듈 수

### 5. 예상 완료일
현재 학습 페이스를 기반으로:
- 남은 모듈 수 × 평균 소요 시간
- 예상 완료 날짜 계산

### 6. 최근 활동
- 최근 5개 커밋 내역
- 날짜 및 커밋 메시지

## 실행 방법

1. **Bash 도구 사용**: `node stats.js` 또는 `npm run stats` 실행
2. **출력 파싱**: stats.js의 콘솔 출력을 가져와 분석
3. **Git 데이터 활용**: 커밋 히스토리에서 날짜 정보 추출
4. **시각화**: 진행 바, 표, 이모지를 활용하여 읽기 쉽게 표현

## 데이터 소스

- **CLAUDE.md**: 체크박스 상태로 진행률 확인
- **Git 로그**: 모듈 완료 날짜 및 학습 활동 추적
- **stats.js**: 통계 계산 및 리포트 생성 스크립트

## 분석 및 인사이트 제공

통계 데이터를 바탕으로 다음을 분석하여 제공하세요:

1. **학습 패턴 분석**
   - 집중 학습 기간 파악
   - 학습 속도 추세

2. **강점 및 성과**
   - 완료율이 높은 과정
   - 일관된 학습 활동 여부

3. **개선 제안**
   - 다음 학습 모듈 추천
   - 복습이 필요한 영역
   - 학습 페이스 조절 조언

4. **동기 부여**
   - 진행 상황에 대한 긍정적 피드백
   - 마일스톤 달성 축하
   - 다음 단계 격려

## 참고 사항

- Git 저장소가 아닌 경우 Git 기반 통계는 생략됩니다
- CLAUDE.md 파일이 없으면 진행률 계산이 불가능합니다
- 모든 날짜는 로컬 시간대 기준입니다
- 통계는 실행 시점의 데이터를 기반으로 합니다
